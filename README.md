# Aun Kitchen 投稿づくり

Aun Kitchen（@aun.kitchen）のInstagram投稿を、メモと写真から作るツールです。AIは、使う人のパソコンに入っているCodexを使います。

## 入れ方

**Windows**：PowerShellを開き、次の1行を貼り付けてEnterを押します。

```
irm https://raw.githubusercontent.com/fuganakai/aun-studio/main/install.ps1 | iex
```

**Mac**：ターミナルを開き、次の1行を貼り付けてEnterを押します。

```
curl -fsSL https://raw.githubusercontent.com/fuganakai/aun-studio/main/install.sh | sh
```

入れ終わると画面が開きます。次からはデスクトップの「Aun投稿づくり」をダブルクリックします。
同じ1行をもう一度実行すると最新版に入れ替わります。作った投稿は消えません。
